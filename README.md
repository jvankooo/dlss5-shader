# dlss5-reshade

DLSS5 Shader for Uncapped

## Install

1. Copy the entire contents of this repo into your Uncapped install folder (the same folder as `Uncapped.exe`), merging it in on top.
2. Launch Uncapped.
3. Open Settings → **Post-processing** — you should see **RenoDX DLSS5** listed there. Enable it.

Press **Home** in-game to open ReShade's own menu, where the neural rendering model, style, intensity, and everything else can be tuned.

## Requirements

- NVIDIA RTX GPU with driver 616.56 or newer (DLSS 5 neural rendering needs both).
